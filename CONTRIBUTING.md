# Contributing to VSQ Studio

Thanks for considering a contribution!

## Before you start
- Check the repository README and existing issues.
- For significant changes, open an issue first to discuss the approach.
- Keep changes focused and explain why they are useful.

## Pull requests
1. Fork the repository and create a descriptive branch.
2. Make your changes and test them where applicable.
3. Update documentation when behavior or setup changes.
4. Open a pull request with a clear summary and relevant context.

## Issues
Include steps to reproduce bugs, expected behavior, actual behavior, and relevant logs or screenshots. Never include secrets or personal data.

Be respectful, constructive, and welcoming. Thank you for helping build the community!
